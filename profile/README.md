We build software for industrial control systems — the kind that runs on a plant floor and has
to keep working. Everything here is open source, tested, and documented.

### Projects

| Project | What it does | Licence |
| --- | --- | --- |
| **[bhtune](https://github.com/bytehound-labs/bhtune)** | Cross-platform PID loop auto-tuner (MRFT) for industrial control loops. | AGPL-3.0 |
| **[opcda-bridge](https://github.com/bytehound-labs/opcda-bridge)** | Rust gateway that makes legacy OPC DA servers reachable from Linux and macOS. | MIT |

### How we work

- **Tested.** Core logic is deterministic and replayable, with CI on every commit.
- **Documented.** Each project ships documentation written for whoever inherits it.
- **Unlocked.** No licence gating, no dongles, no proprietary data formats.
