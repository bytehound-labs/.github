# Support

For help with a ByteHound project, open an issue in the GitHub repository for that project. Search existing issues first, then include the project version, operating system, steps to reproduce the problem, and what you expected versus what happened. Remove credentials and other sensitive information from logs before sharing them.

Do not report security vulnerabilities in public issues. Use GitHub's private vulnerability reporting from the affected repository's **Security** tab, as described in [SECURITY.md](SECURITY.md).
