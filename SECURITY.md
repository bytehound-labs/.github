# Security

Report suspected vulnerabilities privately through GitHub's **Security** tab in the affected repository, using **Report a vulnerability**. Private vulnerability reporting is enabled for:

- [bytehound-labs/bhtune](https://github.com/bytehound-labs/bhtune/security)
- [bytehound-labs/opcda-bridge](https://github.com/bytehound-labs/opcda-bridge/security)
- [bytehound-labs/opc-cli](https://github.com/bytehound-labs/opc-cli/security)

Do not report vulnerabilities in public issues.

Full-mode BHTune is unauthenticated and defaults to binding to loopback; do not expose it to untrusted networks. The OPC DA gateway is unauthenticated and must stay on a trusted network.

For project-specific guidance, see the [BHTune security policy](https://github.com/bytehound-labs/bhtune/blob/main/SECURITY.md) and the [opcda-bridge security policy](https://github.com/bytehound-labs/opcda-bridge/blob/main/SECURITY.md).
